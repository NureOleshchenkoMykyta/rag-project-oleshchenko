# SE-RAG — Software Engineering Architecture & Design Assistant

Наскрізний навчальний проєкт із дисципліни «Технології розробки гібридних систем штучного інтелекту» (ХНУРЕ, група ІПЗм-26-1).

## Сценарій використання
CLI-асистент для інженерів-програмістів та студентів програмної інженерії, який відповідає на архітектурні та інженерні запитання на основі бази знань **Software Engineering Stack Exchange** (ліцензія CC BY-SA 4.0) із обов'язковим цитуванням використаних фрагментів корпусу та відмовою від відповіді за відсутності релевантного контексту.

## Технологічний стек
- **Мова програмування:** Python 3.13
- **Векторне сховище:** ChromaDB (локальне персистентне сховище)
- **Модель ембедингів:** `sentence-transformers/all-MiniLM-L6-v2`
- **Модель генерації:** `qwen2.5:3b` (локально через Ollama)

## Структура проєкту
- `config/` — конфігураційні файли проєкту (`settings.yaml`)
- `docs/` — архітектурні діаграми та проєктна документація
- `reports/` — звіти з лабораторних робіт (`lab-1` .. `lab-5`)
- `src/` — вихідний код модулів (`ingestion`, `embeddings`, `retrieval`, `evaluation`)

## Встановлення та підготовка середовища
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
ollama pull qwen2.5:3b
```
